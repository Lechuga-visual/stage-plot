# Muestra de iconos de GordoStage

Propuesta visual 01 para revisar la familia propia de iconos antes del trazado SVG.

![Muestra de diez iconos GordoStage](gordostage-propuesta-01.png)

La lámina PNG muestra guitarra eléctrica, bajo, batería, micrófono, teclado, monitor de piso, amplificador, caja DI, stagebox y guitarra acústica. Incluye una vista sobre fondo oscuro.

Paleta: carbón, naranja y detalles azules. La muestra fue generada como referencia visual; el detalle se ajustará para su lectura a tamaño pequeño y en PDF.
